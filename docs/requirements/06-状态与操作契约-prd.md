# 分布式即时通信平台｜状态与操作契约

## 会话与消息的生命周期

设备连接经认证进入在线，失联后转为可补拉；消息按服务端接收、持久化、可分发、已读分别标记。

## 权限与操作者

租户管理员开通应用，用户管理自己的设备与会话，群主管理成员，运维只查看授权聚合指标。 在待审批与已完成状态分别检查读写范围，委托与代办保留真实操作者身份。

## 两个关键交互

1. 发送输入租户、会话、客户端消息号与媒体引用，输出服务端序号；结果未知按客户端号查原记录。
2. 历史同步提交设备游标、页大小与会话，返回序号区间、下一游标、保留期外缺口和可读取范围。

## 业务操作与异常回执

| 操作域 | 在当前数据上的处理 | 冲突、拒绝或降级行为 |
|---|---|---|
| 应用与身份 | 服务端从凭据解析租户，设备令牌独立轮换，撤销生效后终止对应连接。 | 伪造租户字段不能读取其他应用消息。 |
| 接入与路由 | 记录设备的连接代际；新连接替换旧连接时延迟到达的断开事件只影响旧代际。 | G1 迟到的下线事件不能踢掉 G2。 |
| 会话与群组 | 私聊身份规范排序去重，群成员的可见序号区间决定能否取历史或媒体。 | 退群后请求新序号返回无权。 |
| 发送与排序 | 给客户端成功前保存消息及分发意图；相同身份不同载荷返回冲突，群内顺序按服务端序号。 | 相同消息号携不同正文不能覆盖原消息。 |
| 离线同步 | 通知只是提示，历史同步按持久记录补拉。过期缺口返回最早可取边界。 | 游标早于保留窗口时明确展示缺失区间。 |
| 多端阅读 | 游标只允许向前且不越过用户可见水位，未读排除本人消息，重读不重复计数。 | 离线设备提交 40 不会让未读数反弹。 |
| 媒体与治理 | 附件引用前检查归属与完成态，撤回用占位事件保留顺序，下载前验证成员关系。 | 他租户文件号不能附到己方会话。 |
| 运维与容量 | 区分接收、落库、分发和客户端确认，慢设备降级为补拉，保留积压年龄与重连指标。 | 数据库未确认的请求不返回已持久回执。 |

## 失联、中断及恢复

同会话分配序号、写消息和分发任务同事务；按发送者及客户端消息号去重，已读只接受更大的可见序号。 中断后先查询最后一个已持久的业务标记，再决定安全重试、补偿或人工复核。对外回执携带对象身份及业务版本。批量操作允许逐项查看成功、失败和未开始。

## 发布级业务断言

入群可见历史按群规则冻结；退群后停止新增消息分发，媒体下载也重验当前资格。 41 只展示一次，新消息 42 依序补齐，两端已读游标最终一致；退群后的新消息对原成员不可见。
